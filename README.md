# ИИ-агент проректора по молодёжной политике ИГУ

Telegram-бот выступает в роли ИИ-помощника проректора по молодёжной политике и воспитательной деятельности Иркутского государственного университета. Он наследует компетенции выпускника направления 39.03.03 «Организация работы с молодёжью» (профиль «Молодёжная политика и технологии работы с молодёжью») и помогает оперативно отвечать на запросы студентов и сотрудников.

## Структура проекта
```
.
├── .env.example            # Шаблон переменных окружения
├── README.md               # Документация и сценарии использования
├── config.py               # Загрузка настроек из окружения
├── main.py                 # Точка входа Telegram-бота
├── requirements.txt        # Зависимости Python
└── bot
    ├── handlers.py         # Обработчики команд и сообщений
    ├── llm_client.py       # Клиент LLM с обработкой ошибок
    └── prompts.py          # Системная подсказка (роль ассистента)
```

## Основные возможности бота
- Отвечает на базовые вопросы о направлениях, инструментах и подразделениях молодёжной политики вуза.
- Помогает формулировать краткие справки, тезисы для выступлений, тексты писем и анонсов.
- Предлагает варианты формулировок и подчёркивает, что финальное решение остаётся за проректором.
- Держит официальный, но живой тон общения и всегда отвечает на русском языке.

## Установка и запуск
1. **Создайте виртуальное окружение и установите зависимости**:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. **Скопируйте шаблон `.env` и заполните токены**:
   ```bash
   cp .env.example .env
   ```
   Обязательные переменные:
   - `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота.
   - `LLM_API_KEY` — ключ провайдера LLM (например, OpenAI или совместимый API).
   - `LLM_MODEL` — целевая модель (например, `gpt-4.1`).
   При необходимости можно задать `LLM_API_BASE` (по умолчанию `https://api.openai.com/v1`).
3. **Запустите бота**:
   ```bash
   python main.py
   ```

## Команды бота
- `/start` — приветствие и краткое описание возможностей.
- `/help` — примеры запросов и подсказки по формату вопросов.
- Любое текстовое сообщение — бот формирует структурированный ответ (3–7 тезисов) через LLM.

## Архитектура и ключевые модули
| Модуль | Функции |
| --- | --- |
| `main.py` | Настройка логирования, инициализация `aiogram`, создание клиента LLM и запуск long polling. |
| `config.py` | Чтение переменных окружения из `.env` с проверкой обязательных значений. |
| `bot/prompts.py` | Системное описание роли ассистента: специалист по молодежной политике, работающий в правовом поле. |
| `bot/llm_client.py` | Асинхронный HTTP-клиент (httpx) для вызова LLM API, журналирование и обработка сетевых ошибок. |
| `bot/handlers.py` | Обработчики `/start`, `/help` и текстовых сообщений, формирование промтов и ответов пользователю. |

## Расширенное описание агента
### Миссия
- Формировать целостную молодёжную политику ИГУ: от диагностики потребностей до внедрения программ развития.
- Повышать вовлечённость студентов в воспитательные, образовательные и социальные проекты университета и региона.
- Координировать взаимодействие между администрацией, студенческими объединениями, внешними партнёрами и государственными структурами.

### Компетенции выпускника 39.03.03, реализованные в агенте
1. **Аналитика молодёжной среды.** Агент собирает и интерпретирует данные, строит сегментацию аудитории и выявляет риски.
2. **Проектирование и управление программами.** Предлагает дорожные карты инициатив, рассчитывает ресурсы, KPI и механизмы мониторинга.
3. **Коммуникативные навыки.** Создаёт медиапланы, разрабатывает сценарии модерации площадок, поддерживает обратную связь со студентами и внешними акторами.
4. **Нормативно‑правовая грамотность.** Контролирует соответствие проектов законодательству, локальным актам и требованиям грантодателей.
5. **Педагогико‑психологические компетенции.** Формирует программы наставничества, профилактики девиантного поведения и инклюзивные практики поддержки.
6. **Цифровые навыки.** Использует BI‑системы, CRM студенческих объединений и автоматизированные трекеры мероприятий.

### Основные модули агента
| Модуль | Функции |
| --- | --- |
| **Стратегический навигатор** | Генерирует стратегии и сценарии развития молодёжной политики, сверяет их с нацпроектами и рейтингами. |
| **Аналитический центр** | Оценивает вовлечённость, анализирует опросы, выявляет потребности целевых групп, предлагает корректировки программ. |
| **Операционный координатор** | Управляет календарём мероприятий, задачами кураторов, бюджетом и отчётностью. |
| **Коммуникационный модуль** | Создаёт контент‑планы, пресс‑релизы, SMM‑кампании, сценарии публичных выступлений проректора. |
| **Профилактика и благополучие** | Отслеживает показатели психологической безопасности, предлагает меры поддержки и координирует работу с соцслужбами. |

### Сценарии использования
1. **Планирование учебного года.** Формируется карта ключевых событий, ответственные, бюджет и KPI.
2. **Подготовка к аккредитации.** Автоматизируется сбор доказательной базы и подготовка отчётов.
3. **Антикризисное управление.** При инцидентах моделируются сценарии реагирования, формируются официальные комментарии.
4. **Грантовая деятельность.** Находятся конкурсы, готовятся заявки, ведётся календарь обязательств.
5. **Мониторинг и оценка.** Собираются метрики и визуализируются для ректората и внешних аудитов.

### Интерфейс взаимодействия
| Канал | Целевая аудитория | Ключевые функции |
| --- | --- | --- |
| **Веб‑кабинет проректора** | Руководство, кураторы направлений | Панель KPI, календарь мероприятий, визуальный конструктор программ, модуль согласования документов. |
| **Мессенджер/чат‑бот** | Студенты, студсоветы, наставники | Быстрые запросы, сбор обратной связи, создание тикетов в CRM, уведомления. |
| **Мобильное приложение кураторов** | Руководители проектов, волонтёры | Чек‑листы, отметка присутствия, загрузка отчётов офлайн, push‑напоминания. |

#### Логика работы интерфейса
1. **Единый API‑шлюз** обеспечивает аутентификацию и маршрутизацию запросов между каналами.
2. **Контекстные карточки** показывают историю взаимодействий, документы и ответственных лиц.
3. **Сценарные кнопки** запускают типовые цепочки («Запустить диагностику», «Сформировать отчёт», «Отправить приглашение»).
4. **Режим совместной работы** добавляет совместное редактирование планов и встроенный видеочат.
5. **Доступность**: адаптивный дизайн, поддержка screen reader, переключение языка и контрастности.

## Метрики эффективности
- Вовлечённость студентов в мероприятия (доля участия, индекс удовлетворённости).
- Количество и качество реализованных проектов, успешность грантов.
- Сокращение времени подготовки отчётности и аккредитационных материалов.
- Индикаторы психологического благополучия и социального климата.

Агент готов к расширению: можно добавить интерфейсы для внешних партнёров, модули прогнозирования карьеры выпускников и расширенную аналитику по регионам присутствия ИГУ.
